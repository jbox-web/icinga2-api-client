# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Added
- Eight object types the gem did not model: `Notification`, `User`,
  `UserGroup`, `TimePeriod`, `HostGroup`, `ServiceGroup`, `Dependency` and
  `ScheduledDowntime`, each with a collection on `Client` (`#notifications`,
  `#users`, `#user_groups`, `#time_periods`, `#host_groups`, `#service_groups`,
  `#dependencies`, `#scheduled_downtimes`).
- `Icinga2::API::Objects`, a generic collection over any catalogued type,
  reachable through `Client#objects(:type)`. `#all` (aliased `#where`) accepts
  `filter:`, `attrs:` and `joins:`, and switches to `POST` with
  `X-HTTP-Method-Override: GET` when the query outgrows the request line.
  `#find` looks an object up by its full Icinga name; `#find_many` resolves a
  batch of names in a single request, in the order asked for.
- `TypeCatalog::Type#filter_variable`, the variable an Icinga2 filter uses to
  address objects of a type (`scheduleddowntime`, not `scheduled_downtime`).
  Derived rather than written out: a wrong prefix answers `404 "No objects
  found"` instead of an explicit error.
- `Icinga2::API::TypeCatalog`, backed by `data/icinga2_types.json`: a frozen
  snapshot of a master's `/v1/types` carrying each type's endpoint, resolved
  fields (inheritance included) and declared references. Regenerated by
  `rake types:snapshot`.
- `Icinga2::API::GenericObject#navigate`, following the references Icinga2
  declares (`ref_type` / `navigation_name` / `array_rank`). A list of
  references is resolved in a single request.
- Chaining from `Host` (`#notifications`, `#scheduled_downtimes`,
  `#dependencies`, `#host_groups`) and from `Service` (`#notifications`,
  `#scheduled_downtimes`, `#service_groups`).
- `Icinga2::API::Error::UnknownType`, raised locally for a type absent from the
  catalog, without a request being sent, and `Error::UnknownRelation` for a
  field that declares no reference. The two are siblings, so rescuing one does
  not swallow the other.
- `Icinga2::API::Objects.escape`, public, for callers building a filter string
  by hand.
- `#acknowledge` and `#remove_acknowledgement` on both `Host` and `Service`
  (`acknowledge-problem` / `remove-acknowledgement` actions).
- Comments: `#add_comment` (returns a `Comment`), `#comments` listing on
  `Host`/`Service`, and `Comment#remove` (`add-comment` / `remove-comment`).
- `#send_notification` on `Host`/`Service` (`send-custom-notification`).
- `#process_check_result` on `Host`/`Service` (`process-check-result`).
- `Client#status` (GET `/v1/status`).
- `Client#subscribe` — Icinga2 event stream (`/v1/events`); blocks and yields
  each event as a Hash.
- `Host#schedule_downtime` and `Host#downtimes` (host-level downtimes), mirroring
  the service-level API.
- `Service#schedule_downtime` / `Host#schedule_downtime` now return the created
  `Downtime` object instead of the raw API payload.
- `Icinga2::API::Error` hierarchy (`NotFound`, `ClientError`, `ServerError`,
  `Timeout`, `ConnectionFailed`); Faraday transport errors are translated into
  it so callers no longer depend on Faraday's exceptions.
- `Error#response` exposes the underlying Faraday response (status/body) when
  available.
- Configurable `open_timeout` / `timeout` connection options (`timeout`
  defaults to 30 seconds).
- `Service#schedule_downtime` validates required parameters and raises
  `ArgumentError` when any is missing.
- Client/connection options are validated: an unknown option (e.g. a typo
  like `verify_ssl` instead of `ssl_options`) now raises `ArgumentError`
  instead of being silently ignored.
- Read-only live integration specs (`spec/integration/`, opt-in via
  `ICINGA_INTEGRATION=1`).
- Gemspec metadata (source code, changelog, bug tracker URIs).

### Fixed
- Multi-valued query parameters were serialised as `attrs[]=a&attrs[]=b`, a
  form Icinga2 **silently ignores**: the request succeeded and every attribute
  came back, so a caller could not tell the restriction had been dropped. They
  are now sent as a repeated key (`attrs=a&attrs=b`).
- `require 'cgi'` replaced by `require 'cgi/escape'`: the full CGI library is
  gone in Ruby 4.0, which the CI matrix covers.
- Object names are now escaped everywhere a filter is built, not only in
  `Objects#find`. A host, service or group whose name carried a double quote
  produced a filter the server could not parse (`host_name=="we"b01"`). This
  also covers `Services#all` and both `#action_filter`, where the flaw
  predates the generic layer.
- The request-size budget deciding between `GET` and the `POST` override is
  measured on the percent-encoded request line instead of the raw bytes. A
  filter full of quotes was underestimated by a factor of up to three, so a
  query the server rejects could still go out as a `GET`.
- The type catalog is now frozen all the way down. It is memoized for the
  whole process, so a single accidental write to a nested Hash corrupted it
  for every later caller.
- `Notification#host`/`#service` and `ScheduledDowntime#host`/`#service` no
  longer re-issue their request on every call when the lookup resolves to
  nothing.
- `Resource#to_h(only:/except:)` no longer mutates the object's attributes.
- Downtimes returned by `host.services.downtimes` are now correctly associated
  with their `Service` (was always `nil`).
- `Hosts#find` returns `nil` instead of crashing on an empty result set, and
  `Hosts#all` skips entries that have no `attrs`.
- `Resource` attribute access no longer collides with real method names.
- `Services`/`Service` no longer cache `all`/`downtimes`, so repeated calls
  reflect the current server state.
- `Interface` tolerates empty or malformed response bodies (returns `[]`).
- `Downtime#cancel` raises instead of silently returning `nil` when nothing was
  cancelled.
- `Downtime` no longer fabricates `1970` timestamps when they are absent.

### Documentation
- The whole public API is now annotated with YARD: parameters, return types,
  raised exceptions and examples. `yard stats` reports **100 % documented**,
  up from 62 %.
- `rake doc` generates it, `rake doc:stats` reports coverage and lists what is
  missing. `.yardopts` runs with `--fail-on-warning`, so an annotation
  referencing something that does not exist fails the task.

### Removed
- `GenericObject#memoized` is private again. It is an internal helper that had
  leaked into the public API; it was only ever called from subclasses.
- The `activesupport` runtime dependency. Its only use was `#to_query`, which
  emitted a query format Icinga2 ignores and has been replaced by hand-rolled
  encoding. The gem now depends on `faraday` and `zeitwerk` only.

### Changed
- The README downtime example no longer pulls in ActiveSupport for `1.hour`.
  It uses `Time` and a plain number of seconds: `DateTime + 3600` would have
  added 3 600 *days*.
- `Hosts`, `Services`, `Host#downtimes`/`#comments` and
  `Service#downtimes`/`#comments` now go through `Objects`. The requests they
  send are unchanged, `POST` included.
- `faraday` constrained to `~> 2.0` and `zeitwerk` to `~> 2.6`.
- Test suite runs with VCR `record: :none` (never contacts a live server).
